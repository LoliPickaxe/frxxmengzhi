# frxxmengzhi（凡人修仙·梦制）

Minecraft 1.12.2 Forge 模组，为 凡人修仙（yvanchuxiuzhen）系列整合包补充玩法扩展。

## 功能

- **灵界维度**：独立维度、穿梭器飞行加速、高空天威（物攻+法攻 ×3）、y≥50000 自动破界
- **灵界灵石矿脉**：按垂直分层（中层/洞壁/深层/熔岩带）生成灵石矿，附 1% 巨型矿脉
- **护盾系统**：X 开关 / C 充能，按境界成长，护盾上限/回复/吸收丹药加成，高频攻击拦截，破盾自动重开
- **灵力电力**：一至五阶发电机/储电器/电池，4 格无线供电，可燃灵石/煤炭等燃料
- **丹药体系**：护盾类永久/临时丹药（练气~化神 5 档）、耐药机制
- **灵界刷怪**：按 结丹/元婴/化神 三档权重召妖兽模组实体，48 格内 ≤18 只
- **灵裕值 / 寿元加成**：灵界每日 +10000 灵裕，按境界永久延寿

## 前置与联动

- Minecraft **1.12.2 + Forge 14.23.5.2860**
- 必装：`fanrenxiuxian`（前置）、`yvanchuxiuzhen`（本体·凡人修仙）
- 联动（缺装则对应功能禁用）：`yvanchujiguan`（功法）、`yvanchuliandan`（炼丹）、`yvanchuyaoshou`（妖兽·灵界刷怪）

## 构建

```
需要 JDK 8（Gradle 4.9 不支持 JDK 17）
set JAVA_HOME=<jdk8路径>
gradlew build --console=plain
产物：build/libs/frxxmengzhi-1.0.0.jar
```

## 命令

| 命令 | 说明 |
|---|---|
| `/frxxlingjie`（`/flj`） | 前往/返回灵界（权限2） |
| `/frxxshield` | 护盾溢出规则（默认：护盾吃不完的伤害溢出为真伤） |
